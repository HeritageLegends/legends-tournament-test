Start New Season

Once this year's tournament is over and you're ready to set up next year's: this archives everything from this season (settings, roster, pairings, scores) into hidden backup tabs in the Google Sheet, then clears pairings and scores and resets every player's team back to unassigned so you can start fresh. Player names, handicaps and tees stay as they are — no need to re-enter the roster. The Hole Handicaps table also stays as-is (only re-enter it if you're changing courses).

Hole Handicaps

Stroke Index ranks each hole 1 (hardest) to 18 (easiest) — this is what Day 2's Live Scoring page uses to work out net scores from each player's Handicap Index on the Roster tab. Par is optional, just for reference. This only needs to be set once per course/tee setup.

Print Blank Scorecards Day 2 only

For players who'd rather write scores by hand than use Live Scoring on a phone. Prints one paper scorecard per match with the tournament name, date, tee, hole-by-hole Stroke Index (and Par, if you've entered it), and each player's handicap strokes marked as dots on the holes they apply to — so they can write in gross scores and circle the ones where a stroke counts. Day 1 isn't offered here since it's one team score per hole, not per player, and doesn't use handicaps.
