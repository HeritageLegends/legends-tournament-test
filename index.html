Start New Season

Once this year's tournament is over and you're ready to set up next year's: this archives everything from this season (settings, roster, pairings, scores) into hidden backup tabs in the Google Sheet, then clears pairings and scores and resets every player's team back to unassigned so you can start fresh. Player names, handicaps and tees stay as they are — no need to re-enter the roster. The Hole Handicaps table also stays as-is (only re-enter it if you're changing courses).

Hole Handicaps

Stroke Index ranks each hole 1 (hardest) to 18 (easiest) — this is what Day 2's Live Scoring page uses to work out net scores from each player's Handicap Index on the Roster tab. Red tees play to a different Stroke Index than every other tee on this course, so there's a separate column just for them: any Roster player whose Tee is "Red" gets strokes from that column instead, everyone else (Gold, White, Blue, etc.) uses the regular Stroke Index column. Par is optional, just for reference, and doesn't change by tee. This table is set once per course/tee setup and shouldn't need changing after that — if it ever does (a new course, a corrected number), edit it directly in the Google Sheet's HoleHandicaps / HoleHandicapsRed tabs rather than here.

Print Blank Scorecards

For players who'd rather write scores by hand than use Live Scoring on a phone. Prints one paper scorecard per match with the tournament name, date, tee, and hole numbers. Day 2 also shows the Stroke Index and each player's handicap strokes marked as dots on the holes they apply to. Day 1 is one row per team instead of per player, since Captain's Choice and Modified Alternate Shot are both one combined score per team per hole — no handicap strokes apply, so there's no Hcp row or dots for that day. Any match printed without a Scorekeeper PIN yet automatically gets one generated and saved, and it's printed right on the card as a backup way to unlock scoring on Live Scoring.

Haven't set that day's pairings yet? "Preview Sample Scorecard" shows the layout with made-up players so you can check it over (and see your Hole Handicaps table reflected in it, for Day 2) before real teams are assembled.
